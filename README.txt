AFNAN PORTFOLIO REDESIGN
========================
Files:
- index.html: portfolio homepage
- style.css: responsive burgundy/cream/black theme and animations
- script.js: scroll reveal, project filters, mobile menu and cursor paw trail
- 9 individual case study pages (4 Meta Ads, 2 SEO, 3 Content Strategy)

HOW TO PUBLISH ON GITHUB PAGES
1. Download and unzip this package.
2. Open your existing GitHub repository: afnan-portfolio.
3. Upload the files inside this folder to the repository root (not the folder itself).
4. Replace the existing index.html, style.css and script.js when prompted.
5. Commit changes to the main branch.
6. Wait a minute, then refresh the GitHub Pages URL.

IMPORTANT
- Contact email is currently afnanmarketing@example.com in index.html. Replace it with your real email or WhatsApp link before publishing.
- The project cards use stylized visual panels until you add your original Meta Ads, Search Console and Instagram screenshots.
- Case study numbers are kept separate and include notes where the exact report date range needs confirmation.
- No leads, revenue, or sales are invented.
