AFNAN PORTFOLIO STARTER
Files: index.html, about.html, services.html, case-studies.html, contact.html, style.css, script.js

Before launch:
1. Replace hello@afnanmarketing.in with your real business email if needed.
2. Replace case-study placeholder boxes with approved original screenshots.
3. Verify every metric, reporting period, and client permission.
4. Upload all files to the root of your GitHub repository.
5. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Test the GitHub Pages URL before connecting your GoDaddy domain.

The contact form opens the visitor's email app; it does not store or send submissions by itself.
