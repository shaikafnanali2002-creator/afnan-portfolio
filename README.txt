HOW TO PREVIEW:
1. Extract this ZIP.
2. Double-click index.html to open it in a browser.
3. Click each project card to open its own case-study page.

HOW TO ADD TO GITHUB:
Upload the extracted files into the root of your afnan-portfolio repository and commit. Keep all HTML files beside style.css and script.js.

HOW TO ADD RESULT SCREENSHOTS:
1. Put your screenshot file (PNG/JPG) in the repository root, OR inside assets/.
2. Open the relevant case-study HTML page on GitHub and click the pencil icon to edit.
3. Find the evidence section and replace the note with, for example:
   <img src="meta-ads-1.png" alt="Meta Ads campaign results screenshot">
   If the image is inside assets/, use src="assets/meta-ads-1.png".
4. Commit changes. Image file names are case-sensitive.
5. Only use the matching screenshot for that specific case study.
